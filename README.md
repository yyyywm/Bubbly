# ❤ 恋爱气泡 - 双人桌面桌宠应用

一个可以置顶在桌面上的可爱桌宠，你和女朋友各自登录后，通过 WebSocket 互相发送消息，对方桌宠头顶会弹出卡通冒泡对话框。

## 功能特性

- **桌面置顶**：窗口始终显示在最前方（alwaysOnTop）
- **鼠标穿透**：默认不干扰桌面操作，右键可拖拽移动
- **气泡动画**：收到消息时头顶弹出对话气泡（淡入上浮 → 停留2.5秒 → 淡出）
- **消息队列**：连续消息不重叠，逐条播放
- **双击发送**：双击桌宠弹出输入框，Enter 发送，3秒后自动收起
- **自动重连**：连接断开后5秒自动重连

## 项目结构

```
pet/
├── server.js      # WebSocket 信令服务器（单文件）
├── main.js        # Electron 主进程（窗口管理）
├── preload.js     # 主进程与渲染进程通信桥梁
├── index.html     # 桌宠 UI 界面
├── renderer.js    # 页面逻辑（WebSocket、动画、交互）
├── package.json   # 项目配置
└── README.md      # 本文件
```

## 启动步骤

### 1. 安装依赖

```bash
cd pet
npm install
```

### 2. 启动服务器

```bash
node server.js
```

启动后终端显示：
```
==================================================
  ❤  恋爱气泡 服务器已启动  ❤
==================================================
  端口: 8080
  局域网连接地址: ws://<你的局域网IP>:8080
  本机连接地址:   ws://localhost:8080
==================================================
```

### 3. 启动客户端

```bash
npm start
```

首次启动后在设置面板中填写：
- **服务器地址**：`ws://localhost:8080`（本机测试）或 `ws://对方IP:8080`
- **房间号**：双方输入相同的房间号（如 `love123`）
- **昵称**：自定义昵称（可选）

### 4. 如何配对

| 场景 | 步骤 |
|------|------|
| **本机测试** | 启动服务器后，运行两个客户端实例，都填写 `ws://localhost:8080`，房间号相同即可 |
| **局域网配对** | A启动服务器，B连接 `ws://A的局域网IP:8080`；A也连接 `ws://localhost:8080`，房间号相同 |
| **公网配对** | A搭建服务器并配置端口转发，B连接 `ws://A的公网IP:8080` |

### 5. 查看局域网IP

```bash
# macOS
ifconfig | grep "inet "
```

找到 `en0` 下的 `inet` 地址（如 `192.168.1.100`），B 端服务器地址填 `ws://192.168.1.100:8080`。

## 操作说明

| 操作 | 功能 |
|------|------|
| **右键拖拽** | 移动桌宠位置 |
| **双击桌宠** | 弹出输入框发送消息 |
| **Enter** | 发送消息 |
| **等待3秒** | 输入框自动收起 |

## 打包发布

### macOS (.dmg)

```bash
npx electron-builder --mac
```

### Windows (.exe)

```bash
npx electron-builder --win
```

> 打包后的程序需确保服务器在运行，客户端启动后填写正确的服务器地址即可。

## 修改服务器地址

客户端启动后在设置面板中直接修改「服务器地址」字段：
- 本机测试：`ws://localhost:8080`
- 局域网：`ws://192.168.x.x:8080`
- 公网：`ws://你的公网IP或域名:8080`
